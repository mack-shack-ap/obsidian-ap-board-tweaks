# AP Board Tweaks

Obsidian plugin for the Americana Pipedream AP Scripts vault.

- Home page pieces: live Short-Form Board columns, recently edited cards, pipeline counts, New script button
- Hover previews on Home cards
- Short-Form Board links open in new tabs
- File explorer: Home pinned to the top of AP Scripts, helper files hidden
- On phones and tablets, applies the Americana Pipedream theme and Home styling (desktop uses the separate theme + CSS snippet)

Install on mobile with BRAT: add this repo as a beta plugin.
